# Prototipo navegable

Abrir `index.html` en un navegador o iniciar un servidor estático desde la raíz del repositorio:

```powershell
python -m http.server 8765
```

Luego abrir `http://127.0.0.1:8765/prototype/`.

Recorrido: completar un correo válido y cualquier contraseña → Inicio → Iniciar captura → escribir referencia → Revisión → Confirmar demostración → Perfil → Cerrar sesión. La pestaña **Elementos** muestra botones y estados. Los datos no salen del navegador ni se persisten.

Este artefacto es una maqueta web móvil aislada. No es implementación Expo/React Native ni conexión con servicios reales.
